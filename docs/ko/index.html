Android 태블릿이나 폰을 Mac의 진짜 세컨드 모니터로 사용하세요.

OpenDisplay의 비공식 오픈소스 Android 클라이언트입니다 — 오리지널 프로젝트는 iOS/iPadOS 클라이언트만 제공합니다. 동일한 네트워크 프로토콜로 통신하기 때문에 Mac 앱 쪽은 전혀 변경할 필요가 없습니다. 이미 Android 태블릿을 가지고 있고 미러링이 아니라 확장 디스플레이를 원하는 사람을 위한 Duet Display, Sidecar, Spacedesk의 무료 대안입니다.

작동 방식

Mac은 그대로 둡니다. 대기하는 쪽은 Android 기기입니다.

Android 기기가 대기하고 Mac이 접속합니다 — 이 방식 덕분에 별도 설정 없이 WiFi로 동작합니다. mDNS 자동 검색을 사용하며, 오리지널 OpenDisplay Mac 앱에는 어떤 변경도 가하지 않습니다.

MAC (서버, 오리지널 OpenDisplay 앱)

  1. CGVirtualDisplay
  2. → ScreenCaptureKit → VideoToolbox H.264
  3. → TCP [4-byte length][Annex-B frame] ═══→
  4. ← control JSON (hello, touch, scroll, ping) ═══

ANDROID (이 프로젝트)

  1. listens on :9000
  2. → MediaCodec → SurfaceView

기능

지금 이미 동작하는 것들.

스펙 시트가 아니라 실제 Mac 앱으로 검증했습니다.

하드웨어 H.264 비디오

MediaCodec으로 Surface에 직접 디코딩, CPU 변환 없음.

자동 검색

mDNS(_opensidecar._tcp) — 같은 네트워크에서 Mac이 Android 기기를 스스로 찾습니다.

터치와 스크롤

Extend 모드에서 손가락 하나는 클릭/드래그, 손가락 두 개는 스크롤이 됩니다. Mac의 Mirror 모드는 보기 전용이라 어떤 클라이언트의 입력도 조용히 무시합니다.

핀치 줌

영상 위에서 두 손가락을 벌리면 로컬에서 확대됩니다. Mirror나 Extend 어느 모드에서든 사용 가능하며 프로토콜 변경도 필요 없고, 터치도 Mac 쪽의 정확한 위치에 전달됩니다. 확대한 뒤에는 손가락 세 개로 드래그해 확대 영역을 이동할 수 있습니다.

원격 커서

점 또는 디코딩된 스프라이트로 Mac의 커서 위치를 실시간으로 반영합니다.

포그라운드 서비스

앱이 백그라운드로 가도 유지되며, 화면 잠금 해제 후에도 정상적으로 재개됩니다.

오류 복구

디코더 오류 발생 시 연결을 끊지 않고 자동으로 키프레임을 요청합니다.

수동 대체 연결

자동 검색이 실패할 때를 위해 편집 가능한 mDNS 이름과 IP:포트 연결을 제공합니다.

USB 액세서리(AOA)

케이블을 꽂고 시스템 프롬프트를 누르기만 하면 됩니다 — adb도, 개발자 옵션도 필요 없습니다.

PIP(화면 속 화면)

연결된 상태로 앱을 벗어나도 영상이 떠 있는 창에서 계속 재생됩니다.

계정 없음, 텔레메트리 없음

오리지널 프로젝트와 같은 철학입니다: 중앙 서버 없음, 외부로 전송되는 데이터 없음.

자주 묻는 질문

자주 묻는 질문.

iOS용 OpenDisplay와 같은 앱인가요?

아닙니다. Kotlin으로 처음부터 새로 작성된 독립 클라이언트로, 오리지널 Mac 앱과 상호운용하기 위해 동일한 네트워크 프로토콜을 구현했습니다. 공식 프로젝트는 iOS/iPadOS 클라이언트만 제공합니다.

Google Play에 있나요?

Google Play 버전은 현재 비공개 테스트 중입니다. 테스터로 참여하고 싶으시면 josepacelli@gmail.com으로 메일 주세요. 그동안은 GitHub Releases로도 배포됩니다 — adb install로 설치하거나 APK를 기기에 복사해서 설치하세요 ("출처를 알 수 없는 앱" 허용 필요).

WiFi가 꼭 필요한가요?

mDNS 자동 검색으로 WiFi를 통해 동작합니다. USB로 네이티브 액세서리(AOA)로 연결할 수도 있습니다 — 케이블을 꽂고 시스템 프롬프트를 누르기만 하면 되며 adb는 필요 없습니다. AOA를 아직 지원하지 않는 Mac 앱을 위한 대체 방법은 저장소를 참고하세요.

Mirror 모드에서도 터치가 되나요?

안 됩니다 — Mac 쪽 Mirror 모드는 보기 전용입니다. Mac 앱은 Extend 모드에서만 터치/스크롤을 받아들입니다(미러 세션에서는 입력 인젝터 자체를 만들지 않습니다). 그래서 여기서 보내는 탭이나 스크롤은 조용히 무시됩니다. 상호작용이 필요하면 Extend 모드를 사용하세요.

아무 Android 태블릿이나 폰에서 동작하나요?

Android 8.0(API 26) 이상이 필요합니다. 실제 기기(Samsung Galaxy Tab S9 FE+, Galaxy Note10+/Tab S7+, Android 12~16)에서 테스트했지만, 아직 다양한 기기에서 폭넓게 검증되지는 않았습니다 — 터치/스크롤/커서는 구현되어 있지만 실사용 검증은 아직 제한적입니다. 참고: v0.0.7 이하 버전은 Android 12~13(API 30-33)에서 실행 시 크래시가 발생합니다. v0.0.8 이상을 사용하세요 (#5에서 수정됨).

Mac 앱에 어떤 변경이라도 가하나요?

전혀 변경하지 않습니다 — 프로토콜 불일치가 있다면 그것은 업스트림이 아닌 이 프로젝트의 책임입니다.

라이선스는 무엇인가요?

GPL-3.0, 오리지널 프로젝트와 동일합니다. 오픈소스이며 상업적 사용을 포함해 자유롭게 사용할 수 있습니다. 배포되는 수정 버전도 동일한 라이선스로 오픈소스를 유지해야 합니다.

프로젝트 후원하기
Ko-fi

OpenDisplay Android 덕분에 모니터를 안 사도 됐다면, 커피 한 잔 사주시는 건 어떨까요.

이건 제가, Jose Pacelli가 저녁과 주말 시간에 혼자 만들고 유지보수하는 사이드 프로젝트입니다 — 회사가 아닙니다.

Ko-fi로 후원해 주시면 이 프로젝트를 계속 유지하고, 후원할 여유가 없는 사람들에게도 무료로 제공할 수 있습니다. 남는 Android 태블릿을 진짜 세컨드 모니터로 바꾸는 가장 좋은 무료 방법이 되는 것이 제 목표입니다.

모니터를 안 사도 됐다면, 작은 팁 하나가 이 프로젝트를 계속 이어가는 힘이 됩니다. 감사합니다.
