AndroidタブレットやスマホをMacの本物のセカンドモニターとして使えます。

OpenDisplayの非公式オープンソースAndroidクライアントです — オリジナルプロジェクトが提供しているのはiOS/iPadOSクライアントのみです。これは同じネットワークプロトコルで通信するため、 Macアプリ側の変更は一切不要です。すでにAndroidタブレットを持っていて、ミラーリングだけでなく拡張ディスプレイが欲しい人向けの、 Duet Display、Sidecar、Spacedeskの無料代替です。

仕組み

Macには一切手を加えません。待ち受けるのはAndroid側です。

Android側が待ち受け、Mac側が接続する — この仕組みのおかげで、手動設定なしでWiFi経由で 動作します。mDNSによる自動検出を使い、オリジナルのOpenDisplay Macアプリには一切変更を加えません。

MAC （サーバー、オリジナルのOpenDisplayアプリ）

  1. CGVirtualDisplay
  2. → ScreenCaptureKit → VideoToolbox H.264
  3. → TCP [4-byte length][Annex-B frame] ═══→
  4. ← control JSON (hello, touch, scroll, ping) ═══

ANDROID （本プロジェクト）

  1. listens on :9000
  2. → MediaCodec → SurfaceView

機能

現時点ですでに動作するもの。

仕様書ではなく、実際のMacアプリで検証済みです。

ハードウェアH.264デコード

MediaCodecでSurfaceに直接デコード、CPU変換なし。

自動検出

mDNS（_opensidecar._tcp）— Macが同じネットワーク上のAndroid端末を自動で見つけます。

タッチとスクロール

Extendモードでは、指1本がクリック/ドラッグに、指2本がスクロールになります。MacのMirrorモードは表示専用で、どのクライアントからの入力も黙って無視します。

ピンチでズーム

映像上で2本指を広げるとローカルでズームします。MirrorモードでもExtendモードでも使え、プロトコル変更は不要、タッチもMac側の正しい位置に届きます。ズーム後は3本指のドラッグで拡大領域内を移動できます。

リモートカーソル

ドットまたはデコードされたスプライトで、Macのカーソル位置をライブに反映します。

フォアグラウンドサービス

アプリがバックグラウンドに回っても維持され、画面ロック解除後も正しく再開します。

エラー復旧

デコーダーエラー時は接続を切らずに自動でキーフレームを要求します。

手動フォールバック

自動検出が失敗したときのために、編集可能なmDNS名とIP:ポート接続を用意しています。

USBアクセサリ（AOA）

ケーブルを挿してシステムのプロンプトをタップするだけ — adbも開発者向けオプションも不要です。

ピクチャー・イン・ピクチャー

接続中にアプリを離れても、映像はフローティングウィンドウで再生され続けます。

アカウント不要、テレメトリなし

オリジナルプロジェクトと同じ理念です：中央サーバーなし、外部に何も送信しません。

よくある質問

よくある質問。

これはiOS版OpenDisplayと同じアプリですか？

いいえ。これはKotlinでゼロから書かれた独立クライアントで、オリジナルのMacアプリと 相互運用するために同じネットワークプロトコルを実装しています。公式プロジェクトが提供しているのは iOS/iPadOSクライアントのみです。

Google Playにありますか？

Google Play版は現在クローズドテスト中です。テスターとして参加希望の方は josepacelli@gmail.comまでメールしてください。 それまでは、GitHub Releasesでも配布しています — adb installでインストールするか、 APKを端末にコピーしてインストールしてください（「提供元不明のアプリ」を許可）。

WiFiは必要ですか？

mDNSによる自動検出でWiFi経由で動作します。USBでネイティブアクセサリ（AOA）として 接続することもできます — ケーブルを挿してシステムのプロンプトをタップするだけで、adbは 不要です。AOA未対応のMacアプリ向けのフォールバックについてはリポジトリを参照してください。

Mirrorモードでタッチはできますか？

できません — Mac側のMirrorモードは表示専用です。MacアプリはExtendモードでしかタッチ/スクロールを 受け付けません（ミラーセッションでは入力インジェクター自体を作成しません）。そのためここから送られる タップやスクロールは黙って無視されます。操作したい場合はExtendモードを使ってください。

どのAndroidタブレットやスマホでも動きますか？

Android 8.0（API 26）以上が必要です。実機（Samsung Galaxy Tab S9 FE+、 Galaxy Note10+/Tab S7+、Android 12〜16）でテスト済みですが、幅広い機種での検証はまだです — タッチ/スクロール/カーソルは実装済みですが、実地検証はまだ限定的です。注意：v0.0.7以前は Android 12〜13（API 30-33）で起動時にクラッシュします。v0.0.8以降を使用してください （#5で修正済み）。

Macアプリに何か変更を加えますか？

一切変更しません — プロトコルの不一致があれば、それは本家ではなくこのプロジェクトの責任です。

ライセンスは何ですか？

GPL-3.0、オリジナルプロジェクトと同じです。オープンソースで、商用利用を含め自由に 使えます。配布する改変版は同じライセンスの下でオープンソースのままである必要があります。
